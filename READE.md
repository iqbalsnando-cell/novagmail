# NovaMail Demo

Template antarmuka workspace yang terinspirasi dari pola dashboard modern. Menggunakan identitas dan aset orisinal.

## Isi folder
- `index.html` — struktur halaman
- `style.css` — desain responsif dan tema terang/gelap
- `script.js` — navigasi, pencarian pesan contoh, modal, dan aktivitas simulasi

## Cara menjalankan
Buka `index.html` di browser. Tidak perlu instalasi atau build tools.

## Deploy ke GitHub Pages
1. Buat repository baru di GitHub.
2. Unggah ketiga file (`index.html`, `style.css`, `script.js`) dan README ini.
3. Buka **Settings → Pages**.
4. Pilih branch utama dan folder `/ (root)`, lalu simpan.

## Keamanan
Ini hanya frontend demo. Tidak ada login sungguhan, koneksi Google, pengumpulan kata sandi, atau pengiriman data ke server. Jangan gunakan untuk meminta kredensial pribadi. Google dan Gmail bukan bagian dari produk demo ini.
